## Instalación

<Code code="bun add @iskra-bun/core @iskra-bun/web-kit" lang="bash" frame="none" />

Una aplicación mínima:

<Code
  code={`import { App } from '@iskra-bun/core';
import { WebDriver } from '@iskra-bun/web-kit';

const app = new App({ name: 'MyApp' });

app.register(new WebDriver({
port: 3000,
routes: [
{
method: 'GET',
path: '/',
handler: () => ({ message: 'Hello from Iskra!' }),
},
],
}));

await app.start();`}

## Por qué Iskra

<CardGrid stagger>
    <Card title="Arquitectura hexagonal" icon="puzzle">
        Puertos y Adaptadores desacoplan tu lógica de negocio de la infraestructura. Cambiá de driver sin tocar el
        código de tu dominio.
    </Card>
    <Card title="Hecho para Bun" icon="rocket">
        APIs nativas de Bun (`bun:sqlite`, WebSocket) para máximo rendimiento, con fallback compatible con Node donde
        hace falta.
    </Card>
    <Card title="Kits modulares" icon="open-book">
        Web, DB, Sockets, KV, Workers, Procesos, Escritorio y Móvil — agregá solo lo que necesites, cada uno como Driver
        o Plugin.
    </Card>
    <Card title="15+ features web" icon="setting">
        Auth, CORS, CSRF, rate limiting, API keys, validación, sesiones, RBAC, OpenAPI y más, resueltos por un
        micro-kernel.
    </Card>
    <Card title="Tipado de punta a punta" icon="approve-check">
        TypeScript en todo, con validación Zod en los límites del sistema y una jerarquía de errores consistente.
    </Card>
    <Card title="Templates y SDKs" icon="document">
        Templates listos para correr y SDKs cliente para Java y Python para consumir tus servicios Iskra desde otros
        lenguajes.
    </Card>
</CardGrid>

## Paquetes

| Paquete                    | Descripción                                                                          |
| :------------------------- | :----------------------------------------------------------------------------------- |
| `@iskra-bun/core`          | Núcleo del framework: App, DI, eventos, logger, errores                              |
| `@iskra-bun/config-kit`    | Carga y validación de configuración de entorno con Zod.                              |
| `@iskra-bun/web-kit`       | Servidor HTTP con Hono, Kernel y 15+ features integradas                             |
| `@iskra-bun/auth-kit`      | Autenticación con better-auth (config + esquema Drizzle), independiente del HTTP.    |
| `@iskra-bun/db-kit`        | Base de datos SQL con Drizzle ORM (PostgreSQL, MySQL, SQLite)                        |
| `@iskra-bun/socket-kit`    | WebSocket nativo de Bun con router y broadcast                                       |
| `@iskra-bun/kv-kit`        | Store Key-Value con adapters Redis y memoria                                         |
| `@iskra-bun/cache-kit`     | Caché de alto nivel (cache-aside, TTL, namespaces, tags) sobre kv-kit.               |
| `@iskra-bun/worker-kit`    | Cola de jobs en background con BullMQ                                                |
| `@iskra-bun/mailer-kit`    | Email independiente del transporte (SMTP/SendGrid/Mailgun/SES).                      |
| `@iskra-bun/storage-kit`   | Almacenamiento de archivos (local, S3/MinIO) con streaming.                          |
| `@iskra-bun/process-kit`   | Gestión de procesos externos (Python, binarios)                                      |
| `@iskra-bun/testing-kit`   | Utilidades de testing (createTestApp, mocks de logger/driver, withTempDir).          |
| `@iskra-bun/desktop-kit`   | Soporte de apps de escritorio con Tauri _(experimental)_                             |
| `@iskra-bun/mobile-kit`    | Soporte de plataformas móviles _(experimental)_                                      |
| `@iskra-bun/db-oracle`     | Soporte de Oracle Database vía bridge/sidecar _(experimental)_                       |
| `create-iskra`             | CLI de andamiaje de proyectos (`bun create iskra`).                                  |

Requiere **Bun v1.3+**. Algunas dependencias nativas también esperan **Node.js v18+**.
